# Openbare aandelenanalyses

Hier kunnen gecontroleerde analyses en onderzoeksrapporten komen. Er is nog geen volledig dossier in deze map gepubliceerd.

Een dossier begint straks met een eigen README: bedrijf en notering, onderzoeksvraag, conclusie, verslagperiode, publicatiestatus, bronnen, onzekerheden en positieverklaring op de publicatiedatum. De README verbindt het rapport met de gebruikte onderdelen van de methode en met de [terugblik](../Archief/README.md) als die er later komt.

Ik publiceer hier geen eerste concepten. Niet-bevestigde gegevens blijven herkenbaar en mogen geen stellige conclusie dragen. Privéwerkaantekeningen en volledig gekopieerde rapporten van derden worden niet standaard meegepubliceerd.
