- [Geschiedenis en belangrijke stromingen van NLP](NLP-Geschiedenis-en-Stromingen.md): de ontwikkeling van modelleren, taalpatronen en latere benaderingen.
- [Tien NLP-presupposities toegepast op beleggen](../../02-Manifesto/02-NLP-Presupposities.md): de praktische uitwerking in het Manifesto.
