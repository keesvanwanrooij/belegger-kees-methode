# Werken aan deze repository

Lees [CLAUDE.md](CLAUDE.md) expliciet voordat je aan deze repository werkt. Dat is de centrale, aanbiederneutrale startpagina voor AI-agents. Neem niet aan dat een bestand automatisch is geladen.

Lees voor de inhoudelijke context [README.md](README.md) en de bij de opdracht betrokken documenten. Als de lokale map `00-Merkgids` aanwezig is, volg de leesroute uit de agentstartpagina. Een openbare clone mag zonder die privémap bruikbaar blijven.

Geen commit, push, publicatie, wijziging van repositoryzichtbaarheid of Git-geschiedenis zonder een nieuwe expliciete opdracht van Kees.
